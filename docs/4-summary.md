## 4.2 프로젝트 회고

### 잘 된 점

* JSP, Servlet, JDBC를 활용하여 회원 관리 및 리뷰 시스템을 구현하였다.
* 회원가입, 로그인, 로그아웃 기능을 통해 사용자 인증 기능을 구현하였다.
* 리뷰 작성, 조회, 삭제 기능과 평점 기능을 구현하여 사용자 간 평가가 가능하도록 하였다.
* 마이페이지에서 회원 정보와 평균 평점, 받은 리뷰 수를 확인할 수 있도록 구현하였다.
* H2 Database를 활용하여 별도의 데이터베이스 서버 없이도 데이터 저장 및 조회 기능이 정상적으로 동작하도록 구현하였다.
* Encoding Filter를 적용하여 UTF-8 기반 한글 처리를 지원하도록 개선하였다.
* **StarUML 설계를 바탕으로 AI에게 구조 정보를 제공하여 백엔드 로직의 정확도를 높였다.**
* ** StarUML과 db를 미리 직접구현하고 ai한테 다른부분을 작성하게하니 바라는대로 구현되었다.**
* **상품 관리의 전 과정(등록, 수정, 조회, 삭제)을 MVC 패턴에 맞게 성공적으로 구현하였다.**
* **`MultipartConfig`를 활용하여 서버 내 물리적 경로에 이미지를 업로드하고 이를 DB와 연동하는 이미지 관리 시스템을 구축하였다.**
* **사용자 편의를 위해 카테고리 필터링 및 다양한 정렬(최신순, 가격순) 기능을 SQL 동적 쿼리로 구현하였다.**

### 아쉬운 점 / 개선 사항

* 초기에는 MySQL Database를 활용하여 구현할 계획이었으나 개발 환경에서 MySQL 서버 연결 및 설정 문제로 인해 정상적인 연동을 완료하지 못하였다.
* 이에 따라 H2 Database를 사용하여 기능 구현을 진행하였으며, 향후에는 MySQL 기반 환경으로 전환하여 테스트를 진행할 필요가 있다.
* 리뷰 수정 기능과 회원 정보 수정 기능은 구현하지 못하였다.
* 현재 UI는 기능 구현 중심으로 작성되어 있어 디자인 개선의 여지가 있다.
* 입력값 검증 및 예외 처리 기능을 더욱 보완할 필요가 있다.


* **회원/리뷰 모듈(H2)과 상품 모듈(MySQL)의 데이터베이스 환경이 일원화되지 않아 통합 관리에 아쉬움이 남는다.**
* **상품 상세 페이지에서 해당 판매자에 대한 리뷰를 바로 확인할 수 있는 연동 기능이 추가되면 좋을 것 같다.**

### 프로젝트 수행 과정에서 배운 점

* Servlet Controller와 JSP를 이용한 MVC 구조의 동작 원리를 이해할 수 있었다.
* JDBC를 활용한 데이터베이스 연동 방법과 DAO 패턴의 활용 방법을 학습할 수 있었다.
* 세션(Session)을 활용한 로그인 유지 및 사용자 인증 방법을 학습하였다.
* 웹 애플리케이션 개발 과정에서 UTF-8 인코딩 처리의 중요성을 확인할 수 있었다.
* H2 Database를 적용하여 데이터 저장 및 조회 기능을 구현하는 경험을 할 수 있었다.

* **XAMPP MySQL 환경에서 직접 데이터베이스 스키마를 설계하고 구축하는 역량을 키웠다.**
* **이미지 파일 업로드 및 서버 저장소 관리 등 실무적인 웹 기능 구현 방식을 익혔다.**
* **시스템 환경 변수 및 설정을 통한 유연한 DB 연결(ProductDao의 connect 로직 등)의 중요성을 배웠다.**
* **서로 다른 기능을 모듈별로 분리하여 개발하고 통합하는 협업 과정의 흐름을 이해하게 되었다.**
