# Requirements_Analysis



### 1. 회원가입 및 로그인
- JSP를 통해 사용자 입력을 받는다.
- Servlet에서 요청을 처리하고 DAO를 통해 DB에 저장한다.
- 로그인 성공 시 Session에 사용자 정보를 저장한다.

---

### 2. 후기 작성 기능
- 사용자는 거래 완료된 상품에 대해 후기 작성 가능
- ReviewServlet에서 요청을 받아 DB에 저장
- 한 상품에 대해 중복 후기 작성 방지 로직 적용

---

### 3. 평점 계산 기능
- 특정 사용자에 대한 모든 리뷰를 조회
- 평균 평점 계산 후 화면에 출력

예시 SQL:
SELECT AVG(rating) FROM reviews WHERE target_user_id = ?

---

### 4. 후기 조회 기능
- 특정 사용자의 후기 리스트 조회
- JSP에서 리스트 형태로 출력

## 상품관리 기능적 요구사항
- |요구사항 | 우선순위
- |상품등록 | 높음 | 
- | 상품삭제 | 높음|
- | 상품수정| 높음|
- | 상품조회 | 높음|
- | 상품찾기 | 높음 |

| 구분    | 요구사항                                 |
| ----- | ------------------------------------ |
| 회원 관리 | 사용자는 회원가입, 로그인, 로그아웃을 할 수 있다.        |
| 상품 관리 | 사용자는 중고 상품을 등록, 수정, 삭제, 조회할 수 있다.    |
| 상품 검색 | 사용자는 키워드로 상품을 검색할 수 있다.              |
| 거래 관리 | 사용자는 상품의 거래 상태를 확인하고 거래를 진행할 수 있다.   |
| 후기/평점 | 거래 완료 후 상대방에게 후기와 평점을 남길 수 있다.       |
| 마이페이지 | 사용자는 자신의 정보, 등록 상품, 후기 내역을 확인할 수 있다. |


## 비기능적 요구사항
상품 등록시 대분류,중분류,소분류에따른 상품 분류
사용자가 정한 우선순위 대로 상품 나열


| 구분     | 내용                                             |
| ------ | ---------------------------------------------- |
| 사용성    | 대학생이 쉽게 사용할 수 있도록 단순한 화면 구조를 제공한다.             |
| 유지보수성  | MVC 패턴을 적용하여 Model, View, Controller 역할을 분리한다. |
| 확장성    | 추후 채팅, 신고, 찜 기능 등을 추가할 수 있도록 설계한다.             |
| 신뢰성    | 후기와 평점 기능을 통해 사용자 간 거래 신뢰도를 높인다.               |
| 데이터 관리 | JDBC를 활용하여 회원, 상품, 거래, 후기 데이터를 DB에 저장한다.       |



## 시스템 설계
2-1. MVC 구조
| 구성         | 역할                                                       |
| ---------- | -------------------------------------------------------- |
| Model      | 회원, 상품, 거래, 후기, 평점 데이터를 처리한다. DAO/DTO를 통해 DB와 연동한다.      |
| View       | JSP/HTML/CSS를 이용해 상품 목록, 상세 페이지, 회원 페이지, 후기 작성 화면을 보여준다. |
| Controller | 사용자의 요청을 받아 적절한 Model을 호출하고 결과를 View로 전달한다.              |


2-2. 데이터베이스 주요 필드

users 테이블

| 필드명        | 설명       |
| ---------- | -------- |
| user_id    | 회원 고유 ID |
| username   | 로그인 ID   |
| password   | 비밀번호     |
| nickname   | 닉네임      |
| email      | 이메일      |
| rating_avg | 평균 평점    |
| created_at | 가입일      |


products 테이블

| 필드명         | 설명           |
| ----------- | ------------ |
| product_id  | 상품 고유 ID     |
| seller_id   | 판매자 ID       |
| title       | 상품명          |
| description | 상품 설명        |
| price       | 가격           |
| category    | 카테고리         |
| status      | 판매중/예약중/거래완료 |
| created_at  | 등록일          |




reviews 테이블

| 필드명            | 설명       |
| -------------- | -------- |
| review_id      | 후기 고유 ID |
| transaction_id | 거래 ID    |
| reviewer_id    | 작성자 ID   |
| target_user_id | 대상자 ID   |
| rating         | 평점       |
| comment        | 후기 내용    |
| created_at     | 작성일      |
